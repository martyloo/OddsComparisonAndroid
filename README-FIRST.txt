ODDS COMPARE - ANDROID PROJECT

1. Install Android Studio.
2. Unzip this project.
3. Open the OddsCompareAndroid folder in Android Studio.
4. Let Gradle sync. If Android SDK 37 or Build Tools are requested, install them.
5. Open Device Manager and create an Android phone emulator, or connect a real Android device.
6. Press the green Run triangle.

TO BUILD AN APK:
Build > Build App Bundle(s) / APK(s) > Build APK(s)

The approved HTML interface is at app/src/main/assets/www/index.html.
The app needs internet access to call the live PythonAnywhere odds API.
